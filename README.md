# Дом Мира: сайт, заявки, админка и боты

Сайт строительной компании «Дом Мира» (ООО «ГК ВЕСЬ МИР») с приёмом заявок, Telegram ботами, веб-админкой и аналитикой.

- Сайт: https://dom-mira.vercel.app (временный адрес до подключения домена)
- Админка: https://dom-mira.vercel.app/admin/
- Админ-бот для сотрудников: [@dommira_zayavki_bot](https://t.me/dommira_zayavki_bot)
- ИИ-консультант для клиентов: [@dommira_consult_bot](https://t.me/dommira_consult_bot)

## Что внутри

| Часть | Где | Что делает |
|---|---|---|
| Главная «Строительство домов» | `index.html` | Реальные объекты, этапы стройки, цены, условия договора, материалы, вопросы, заявка, расчёт стоимости |
| «Отделочные работы» | `otdelka/index.html` | Три сценария, этапы, цены, надзор, интерьеры, вопросы, заявка |
| «Проектирование» | `proektirovanie/index.html` | Прежняя страница, формы подключены к системе заявок |
| Документы | `privacy/`, `soglasie/`, `cookies/` | Политика, отдельное согласие по 152-ФЗ, политика cookie |
| Стили и скрипты сайта | `src/site/` | Токены, компоненты, формы с защитой от спама, cookie, Метрика, калькулятор, галерея |
| Админка | `admin/index.html`, `src/admin/` | React: заявки, диалоги, статистика, контент, база знаний ИИ, настройки, пользователи и роли, журнал |
| API | `api/handler.js` → `server/app.js` | Одна функция Vercel обслуживает все адреса `/api/*` |
| База | `db/migrations/` | PostgreSQL (Neon, Франкфурт) |
| Исследования | `research/` | ЦА, план Метрики, SEO, безопасность, юридический чек-лист, промпты |

Старая страница `/stroitelstvo-domov/` заменена главной, на неё стоит постоянный редирект.

## Как идёт заявка

1. Посетитель заполняет форму или расчёт на сайте. Браузер решает небольшую задачу (защита от ботов без капчи), форма отправляет данные, UTM метки и ClientID Метрики на `/api/leads`.
2. Сервер проверяет поля, лимиты и признаки спама, склеивает повторы, сохраняет заявку в базу.
3. Админ-бот присылает карточку в группу и привязанным сотрудникам: кнопки «Взять в работу», «Статус», «Открыть в админке».
4. Если заявку не взяли за 15 минут (настраивается), бот напоминает, через 2 часа сообщает владельцу. Если Telegram не принял сообщение, доставка повторяется.
5. Смена статуса в админке или в боте пишется в историю и ставит офлайн конверсию для Метрики.
6. ИИ-консультант в Telegram отвечает по базе знаний, уточняет задачу, спрашивает согласие и сам создаёт заявку с выжимкой диалога. Менеджер может ответить клиенту прямо из админ-бота (ответом на сообщение) или из админки.
7. По понедельникам отчёт за неделю уходит в админ-бот текстом и файлом Excel, копия доступна в Google Таблицах по ссылке из раздела «Статистика».

## Локальный запуск

```sh
npm ci
npm run dev          # сайт, админка и API на http://127.0.0.1:5173
npm test             # юнит-тесты
npm run build        # сборка в dist/
npm run check        # вёрстка на 9 ширинах: прокрутка и картинки
```

Секреты лежат в `.env.local` (в git не попадает). Шаблон: `.env.example`.

## Переменные окружения (Vercel → Settings → Environment Variables)

| Переменная | Зачем |
|---|---|
| `DATABASE_URL` | Подключение к PostgreSQL (выдаёт интеграция Neon) |
| `SITE_URL` | Адрес сайта для ссылок, canonical и вебхуков |
| `SITE_INDEXABLE` | `true` после подключения боевого домена, иначе сайт закрыт от индексации |
| `SESSION_SECRET`, `POW_SECRET`, `IP_HASH_SALT` | Подписи сессий, защиты форм, хеш IP |
| `CRON_SECRET` | Защита ежедневной задачи (Vercel Cron передаёт его сам) |
| `BACKUP_KEY` | Ключ шифрования резервных копий, хранить отдельно |
| `TG_ADMIN_BOT_TOKEN`, `TG_ADMIN_BOT_USERNAME` | Админ-бот |
| `TG_CLIENT_BOT_TOKEN`, `TG_CLIENT_BOT_USERNAME` | ИИ-консультант |
| `TG_WEBHOOK_SECRET` | Проверка, что запросы пришли от Telegram |
| `GROQ_API_KEY`, `OPENROUTER_API_KEY`, `CEREBRAS_API_KEY`, `GEMINI_API_KEY`, `MISTRAL_API_KEY` | Бесплатные модели для ИИ-консультанта (любые из них) |
| `YANDEX_API_KEY`, `YANDEX_FOLDER_ID` | Алиса AI через Yandex AI Studio |
| `VITE_YM_ID`, `YM_COUNTER_ID` | Номер счётчика Яндекс Метрики (114151715), встраивается при сборке |
| `YANDEX_VERIFICATION`, `GOOGLE_SITE_VERIFICATION` | Мета теги подтверждения прав в Вебмастере и Search Console (после подключения домена) |
| `YANDEX_METRIKA_TOKEN` | OAuth токен для автоматической загрузки офлайн конверсий (по желанию) |

## Первичная настройка

```sh
npm run db:migrate                                  # таблицы
npm run db:seed -- --login=owner --name="Имя"       # роли, владелец, база знаний; пароль запишется в .env.local
npm run tg:setup -- --url=https://адрес-сайта        # вебхуки, команды и описания ботов
node scripts/prepare-objects.mjs                     # фото объектов с gkvesmir.ru в public/images/objects
```

Деплой: `vercel deploy --prod` из корня проекта (проект `dom-mira` в команде Vercel `srgcompany`).

Ежедневная задача (`/api/cron/daily`, 09:00 МСК): резервная копия владельцу в Telegram, загрузка офлайн конверсий в Метрику, уборка служебных таблиц, проверка вебхуков, по понедельникам недельный отчёт. Напоминания о необработанных заявках проверяются при каждой новой заявке, при каждом действии в админ-боте, при открытии админки и в ежедневной задаче. Для проверки строго каждые 15 минут подготовлен `.github/workflows/tick.yml`: чтобы его добавить, нужен токен GitHub с правом `workflow` (`gh auth refresh -s workflow`), либо на тарифе Vercel Pro можно поставить крон `*/15 * * * *` прямо в `vercel.json`.

## Контент без программиста

Телефон, почта, часы работы, объявление, цены, акции и вопросы обеих страниц меняются в админке, раздел «Контент сайта». Посетители видят изменения в течение минуты, в HTML для поисковиков они попадают при следующей сборке. База знаний ИИ-консультанта редактируется в разделе «База знаний ИИ», там же можно проверить ответ модели.
