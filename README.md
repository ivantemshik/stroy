# Stroy — Дом Мира

Адаптивный лендинг строительной компании. Только фронтенд: HTML, CSS, JavaScript и Vite. Без сервера, базы данных и сторонней аналитики.

Опубликованная версия: https://dom-mira-landing.vercel.app

GitHub Pages: https://ivantemshik.github.io/stroy/ (публикация из ветки `main` через GitHub Actions).

Отдельная страница услуги «Строительство домов»: https://dom-mira-landing.vercel.app/stroitelstvo-domov/. Исходник — `stroitelstvo-domov/index.html`, стили — `src/construction.css`, дополнительная логика — `src/construction.js`. Референс и промпты фотографий — `design/construction-page.md`.

Страница услуги «Проектирование домов»: https://dom-mira-landing.vercel.app/proektirovanie/. Сверстана по макету Figma «Проектирование домов / Desktop 1440». Исходник — `proektirovanie/index.html`, стили — `src/proektirovanie.css`, логика галереи разделов и заявки — `src/proektirovanie.js`. Изображения собираются из `photos/` и `design/planning.svg` командой `node scripts/prepare-proektirovanie.mjs`.

## Локальный запуск

```sh
npm ci
npm run dev
```

Сборка: `npm run build`. Готовая страница находится в `dist/`. Настройки Vercel — в `vercel.json`.

Vite собирает две самостоятельные HTML-страницы через `vite.config.js`. Общая логика меню, расчета и модальных окон подключается из `src/main.js`.

## Поведение

- Мобильное меню, окна с описанием услуг и раскрывающиеся вопросы.
- Блок «Наши проекты» по дополнительному референсу Canva: пять фотокарточек, циклическое листание на широком экране, прокрутка и свайп на телефоне. Карточки открывают описания направлений. Референс и промпты изображений — `design/projects-block.md`.
- Четырехшаговый расчет по площади и виду работ. Цены из исходного отчета, без материалов. Это ориентир, не смета.
- Обращение формируется через `mailto:info@gkvesmir.ru`. Письмо отправляет сам посетитель в почтовой программе. Введенные данные на сервер не передаются.
- Сгенерированные фотографии обозначены на странице как визуализации. Реальные работы доступны по ссылке на портфолио компании.
- Блок отзывов содержит четыре явно обозначенные карточки-заглушки по просьбе заказчика. Аватарки — сгенерированные портреты вымышленных людей. Имена, даты, фотографии, оценки и тексты можно заменить реальными данными в секции `#reviews` файла `index.html`.

## Материалы

Источник содержания — `Обзор_ГК_ВесьМир.md`. Оригинальный референс — предоставленный JPG из Downloads. Детали Canva взяты из проекта `DAHaI2y_in0`. Источники и промпты — `design/ASSETS.md`. Шрифт Manrope хранится локально, лицензия — `public/fonts/OFL.txt`.

## Проверка

`npm run check` проверяет страницу на ширинах 320, 375, 390, 480, 600, 768, 1024, 1440 и 1920 px, загруженность изображений и шрифтов, отсутствие горизонтальной прокрутки, расчет, переходы модальных окон, FAQ и мобильное меню. Результат — `qa/results.json`; снимки — `qa/`.

В проверке используется установленный локальный Chromium, если он доступен; на другом компьютере установите Chromium командой `npx playwright install chromium`.

`npm run check:construction` дополнительно проверяет отдельную страницу на тех же девяти ширинах, галерею и ее клавиатурное управление, возврат фокуса, тип объекта в форме, проверку контакта и предварительный расчет. Результат — `qa/construction-results.json`.

Генерация адаптивных WebP из оригиналов: `node scripts/prepare-assets.mjs`.
