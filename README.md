# Дом Мира: сайт, заявки, админка и боты

Сайт строительной компании «Дом Мира» (ООО «ГК ВЕСЬ МИР») с приёмом заявок, Telegram ботами, веб-админкой и аналитикой.

- Сайт: https://dom-mira.vercel.app (временный адрес до подключения домена)
- Админка: https://dom-mira.vercel.app/admin/
- Админ-бот для сотрудников: [@dommira_zayavki_bot](https://t.me/dommira_zayavki_bot)
- ИИ-консультант для клиентов: [@dommira_consult_bot](https://t.me/dommira_consult_bot)

## Как идёт заявка

1. Посетитель заполняет форму или расчёт на сайте. Браузер решает небольшую задачу (защита от ботов без капчи), форма отправляет данные, UTM метки и ClientID Метрики на `/api/leads`.
2. Сервер проверяет поля, лимиты и признаки спама и сохраняет заявку в базу. Повтор той же отправки (один ключ отправки) второй заявки не создаёт. Новое обращение с тем же телефоном или почтой становится отдельной заявкой с пометкой «возможный повтор №…»: связь проверяет менеджер, а форма никому не сообщает номера чужих заявок.
3. Админ-бот присылает карточку в группу и привязанным сотрудникам: кнопки «Взять в работу», «Статус», «Открыть в админке».
4. Если заявку не взяли за 15 минут (настраивается), бот напоминает, через 2 часа сообщает владельцу. Если Telegram не принял сообщение, доставка повторяется.
5. Смена статуса в админке или в боте пишется в историю и ставит офлайн конверсию для Метрики.
6. ИИ-консультант в Telegram сначала показывает отметку согласия: до неё ничего не сохраняет и не передаёт модели и менеджерам. Потом отвечает по базе знаний и прайсу сайта, уточняет задачу и сам создаёт заявку с выжимкой диалога. Телефон и почту из сообщений сохраняет сам, в модель они не уходят. Менеджер может ответить клиенту прямо из админ-бота (ответом на сообщение) или из админки.
7. По понедельникам отчёт за неделю уходит в админ-бот текстом и файлом Excel, копия доступна в Google Таблицах по ссылке из раздела «Статистика».

## Локальный запуск

```sh
npm ci
npm run dev          # сайт, админка и API на http://127.0.0.1:5173
npm test             # юнит-тесты
npm run build        # сборка в dist/
npm run check        # вёрстка на 9 ширинах: прокрутка и картинки
```

Секреты лежат в `.env.local` (в git не попадает). Шаблон: `.env.example`.

## Переменные окружения (Vercel → Settings → Environment Variables)

| Переменная | Зачем |
|---|---|

| `BACKUP_KEY` | Ключ шифрования резервных копий, хранить отдельно |
| `TG_ADMIN_BOT_TOKEN`, `TG_ADMIN_BOT_USERNAME` | Админ-бот |
| `TG_CLIENT_BOT_TOKEN`, `TG_CLIENT_BOT_USERNAME` | ИИ-консультант |

## Первичная настройка

```sh
npm run db:migrate                                  # таблицы
npm run db:seed -- --login=owner --name="Имя"       # роли, владелец, база знаний; пароль запишется в .env.local
npm run tg:setup -- --url=https://адрес-сайта        # вебхуки, команды и описания ботов
node scripts/prepare-objects.mjs                     # фото объектов с gkvesmir.ru в public/images/objects
```

Деплой: `vercel deploy --prod` из корня проекта (проект `dom-mira` в команде Vercel `srgcompany`).

Ежедневная задача (`/api/cron/daily`, 09:00 МСК): резервная копия владельцу в Telegram, загрузка офлайн конверсий в Метрику, уборка служебных таблиц, проверка вебхуков, по понедельникам недельный отчёт. Напоминания о необработанных заявках проверяются при каждой новой заявке, при каждом действии в админ-боте, при открытии админки и в ежедневной задаче. Для проверки строго каждые 15 минут подготовлен `.github/workflows/tick.yml`: чтобы его добавить, нужен токен GitHub с правом `workflow` (`gh auth refresh -s workflow`), либо на тарифе Vercel Pro можно поставить крон `*/15 * * * *` прямо в `vercel.json`.

## Открытие сайта для поиска

Пока сайт на временном адресе, он закрыт от индексации: метатег `robots` на страницах ставится в `noindex, nofollow`, а `robots.txt` запрещает обход. Оба переключаются одной переменной, правка кода не нужна. Заголовок `X-Robots-Tag: noindex` в `vercel.json` относится только к админке и остаётся всегда.

1. Подключить рабочий домен в Vercel (Settings, Domains) и задать `SITE_URL=https://домен`.
2. Задать `SITE_INDEXABLE=true` и выкатить сайт: `vercel deploy --prod`.
3. Проверить `https://домен/robots.txt` (правило `Clean-param` для меток рекламы и ссылка на sitemap) и `https://домен/sitemap.xml` (адреса на рабочем домене).
4. Подтвердить права в Яндекс Вебмастере и Google Search Console. Лучше записью TXT в DNS домена: она не зависит от хостинга и не требует правки сайта. Если DNS недоступен, задать `YANDEX_VERIFICATION` и `GOOGLE_SITE_VERIFICATION` (значения из сервисов) и выкатить сайт: метатеги появятся на главной.
5. В Вебмастере указать регион «Москва и Московская область», отправить `sitemap.xml` в обоих сервисах, добавить домен в счётчик Метрики 114151715, выдать доступы владельцу компании.

## Плановые задачи и напоминания

Ежедневная задача запускается кроном Vercel. Проверка напоминаний, повтор недоставленных карточек и упавших обновлений Telegram (`/api/cron/tick`) принимает только запрос с заголовком `Authorization: Bearer <CRON_SECRET>`. Для запуска каждые 15 минут подготовлен `.github/workflows/tick.yml`: в репозитории нужен секрет `CRON_SECRET` и переменная `SITE_URL`, а для отправки самого файла токен GitHub с правом `workflow`. На тарифе Vercel Pro то же делается кроном `*/15 * * * *` в `vercel.json`.

## Фото и кэш браузера

Фото хранятся в браузере посетителя год. При сборке к адресу каждого фото в разметке добавляется метка версии из содержимого файла (`?v=…`), фото объектов в фотоотчёте получают общую метку папки. Поэтому фото можно заменять под тем же именем: адрес поменяется сам, и все посетители увидят новое.

## Контент без программиста

Телефон, почта, вопросы главной и отделки, тексты и цифры блока «О компании» и полный прайс (пять групп) меняются в админке, раздел «Контент сайта». Прайс выводится под плитками цен на главной и «Отделке», в таблице «Проектирования», в разметке для поиска и в ответах ИИ-консультанта. Три крупные плитки цен заданы в вёрстке. Посетители видят изменения в течение минуты, в HTML для поисковиков они попадают при следующей сборке. База знаний ИИ-консультанта редактируется в разделе «База знаний ИИ», там же можно проверить ответ модели.

## Стиль и ночное фото

Главная страница это исходный лендинг прежнего дизайнера (`dom-mira-landing.vercel.app`), его вёрстка и стиль (`src/style.css`, `src/main.js`) не менялись. Адаптированы тексты, фото и блоки: «Наши проекты» показывают реальные объекты компании, ссылки ведут на «Отделку» и «Проектирование», расчёт и форма в подвале отправляют заявки в систему. «Отделка» собрана по той же структуре. Шапка, подвал с контактами и окна (расчёт, услуги, «О работе сайта», фотоотчёт) общие для всех страниц: `src/site/partials/header.html` и `footer.html`. Дополнения к исходному стилю лежат отдельно в `src/addons.css`.

Тёмная тема включается для всего сайта кнопкой с луной в шапке любой страницы, выбор запоминается в браузере. По умолчанию сайт следует настройке системы: тему ставит маленький скрипт в `<head>` до отрисовки, поэтому страница не мигает. Ночные цвета лежат в `src/addons.css` (блок «Тёмная тема всего сайта»): исходный стиль задаёт часть цветов прямо в правилах, поэтому у каждого такого правила там есть ночная пара. При переключении цвета плавно перетекают, на главной дневное фото первого экрана сменяется ночным, загораются звёзды и пролетает падающая звезда. Ночное фото делается в Codex по промптам из `design/hero-night-prompts.md`, выбранный вариант кладётся в `design/sources/hero-night/hero-night.webp` и `hero-night-mobile.webp`, размеры для сайта собирает `node scripts/prepare-hero.mjs`. Пока ночного фото нет, скрипт делает временную версию из дневного.

На телефоне блоки ужаты так, чтобы каждый помещался примерно в один экран: отзывы листаются вбок, «Наши услуги» идут списком с маленькими фото, окна услуг открываются во весь экран с квадратным фото сверху. Компьютерная версия при этом не меняется.

Порядок блоков главной и «Отделки» выбран по исследованию сайтов конкурентов: [research/blocks-competitors.md](research/blocks-competitors.md). Главная: первый экран, «Наши услуги» (8 направлений), «Наши проекты», «Сколько стоят работы», «Как идёт работа», «О компании», отзывы, вопросы. «Отделка»: первый экран, «С чем к нам приходят», «Из чего состоит отделка», «Наши интерьеры», «Что проверяем в доме до старта», этапы, цены с формой, вопросы.
