# Проверка безопасности: сайт, формы, API, боты, база

Проверено 9 ноября 2026 года на https://dom-mira.vercel.app и в коде ветки `site-v2-backend-bots`.

## Итог

Критичных уязвимостей не найдено. Все проверки ниже выполнены запросами к боевому API, результаты совпали с ожидаемыми. Главный открытый риск не технический, а правовой: база с персональными данными находится во Франкфурте (см. раздел 8 и `legal-checklist.md`).

## 1. Доступы и учётные записи

| Проверка | Результат |
|---|---|
| API админки без входа | 401, данных не отдаёт |
| Изменяющий запрос с чужого сайта (заголовок Origin) | 403 «Запрос с чужого сайта» |
| Изменяющий запрос без служебного заголовка админки | 403 |
| Скачивание резервной копии без входа | 401 |
| Неверный пароль | 401, после 5 ошибок учётная запись блокируется на 15 минут, с одного IP не больше 20 попыток за 15 минут |
| Пароли | Хранятся как scrypt хеш с солью, минимум 10 символов с буквами и цифрами |
| Сессии | Случайный идентификатор с HMAC подписью в cookie HttpOnly, Secure, SameSite=Lax, хранятся в базе, 14 дней, отзываются при смене пароля и отключении сотрудника |
| Права | Проверяются на сервере в каждом маршруте: 16 прав, 4 роли, права ролей редактируются, владельца может менять только владелец |
| Журнал действий | Входы, ошибки входа, изменения заявок, выгрузки, настройки, контент, база знаний, пользователи, скачивание копий |

Рекомендация на будущее: второй фактор входа через админ-бот (код в Telegram) для ролей владельца и администратора.

## 2. Формы и защита от спама

| Проверка | Результат |
|---|---|
| Заявка без решения задачи | 400 `challenge` |
| Заполненное скрытое поле | Ответ «принято», заявка не сохраняется (бот не узнаёт, что его поймали) |
| Слишком быстрая отправка, ссылки и спам-слова | Заявка сохраняется со статусом «Спам», уведомление не отправляется |
| Повтор решения задачи | Отклоняется, решение одноразовое и живёт 20 минут |
| Частые отправки с одного IP | Больше 6 за 10 минут: 429 |
| Повторная заявка с того же телефона | Склеивается с первой в течение 30 минут, в истории появляется запись |
| Длина полей | Обрезается на сервере, HTML не принимается, телефон и почта проверяются |

Задача для браузера (перебор числа по SHA-256 с подписью сервера) работает без сторонних капч: Cloudflare Turnstile в России работает нестабильно, а Яндекс SmartCaptcha требует платёжного аккаунта в Yandex Cloud.

## 3. API и вебхуки

| Проверка | Результат |
|---|---|
| Вебхук Telegram без секрета | 401, Telegram передаёт секрет в заголовке `X-Telegram-Bot-Api-Secret-Token` |
| Повторная доставка одного обновления Telegram | Отбрасывается по `update_id` |
| Ежедневная задача без `CRON_SECRET` | 401 |
| Лента Google Таблиц без ключа | 403, ключ можно перевыпустить в админке |
| SQL инъекции | Все запросы параметризованы (postgres.js), сортировка только из белого списка |
| XSS | Админка на React экранирует вывод, контент сайта экранируется при сборке и в браузере, сообщения в Telegram экранируются, ответы ИИ уходят обычным текстом |

## 4. Заголовки сайта

`Strict-Transport-Security`, `Content-Security-Policy` (скрипты только свои и Яндекс Метрики, единственный встроенный скрипт разрешён по хешу), `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`. Админка дополнительно: `X-Frame-Options: DENY`, `X-Robots-Tag: noindex`, `Cache-Control: no-store`. HTTPS выдаёт Vercel автоматически.

## 5. ИИ-консультант

- Модель видит только базу знаний и переписку, телефон в запрос не передаётся (вместо него «получен»).
- Системный промпт запрещает раскрывать инструкции, менять правила по просьбе собеседника, обещать то, чего нет в базе знаний, просить паспорт и данные карт.
- У бота нет доступа к базе и действиям: он только отвечает текстом и создаёт заявку после согласия клиента.
- Лимиты: 25 сообщений за 10 минут и 80 в сутки на клиента, затем разговор передаётся менеджеру. Это же защищает бесплатные лимиты моделей.
- Клиент может удалить свои данные командой `/delete`.

## 6. Секреты

- Все ключи и токены только в переменных окружения Vercel и в локальном `.env.local`, который не попадает в git.
- Репозиторий публичный: перед коммитом проверено, что токенов ботов и паролей в отслеживаемых файлах нет.
- `npm audit`: 0 уязвимостей в зависимостях.
- Токены ботов показывались в чате с @BotFather у владельца аккаунта Telegram. Если к этому аккаунту есть чужой доступ, токены стоит перевыпустить командой `/revoke` и обновить переменные в Vercel.

## 7. Резервное копирование

- Ежедневно в 09:00 МСК полная копия базы шифруется AES-256-GCM ключом `BACKUP_KEY` и уходит владельцу в админ-бот. Без ключа файл не читается.
- Скачать копию можно в админке (право «Скачивать резервные копии»), восстановление: `scripts/restore-backup.mjs`.
- Дополнительно Neon хранит историю изменений для восстановления на момент времени (срок зависит от тарифа Neon).
- Ключ `BACKUP_KEY` нужно сохранить отдельно от Vercel (например, в менеджере паролей владельца), иначе при потере проекта копии не расшифровать.

## 8. Риски и что сделать

| Риск | Что сделать |
|---|---|
| База во Франкфурте, а ч. 5 ст. 18 152-ФЗ требует первичной записи данных граждан РФ в базу в России | До боевого запуска перенести базу в российское облако (Yandex Cloud, Timeweb, Selectel): это смена `DATABASE_URL` и `npm run db:migrate` |
| Тариф Vercel Hobby рассчитан на некоммерческое использование | Для коммерческого сайта перейти на Pro или перенести проект в аккаунт заказчика |
| Доступность зарубежного хостинга из России | После подключения домена проверить открытие сайта у разных провайдеров, при проблемах поставить российский CDN или хостинг |
| Один владелец с доступом | Добавить второго сотрудника с ролью «Администратор», чтобы не потерять доступ |
| Нет второго фактора входа | Добавить код подтверждения через админ-бот |
